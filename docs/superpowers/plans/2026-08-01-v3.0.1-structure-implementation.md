# v3.0.1 implementation plan — structure only

Design: [2026-08-01-v3.0.1-structure-design.md](../specs/2026-08-01-v3.0.1-structure-design.md)
(batya-approved). Read it first; this plan does not restate its reasoning.

## The rule that governs every task

**No existing test or fixture may change by a single byte.** Task 1 adds exactly one new test
file; nothing else under `Tests/`, `agent/tests/` or `fixtures/` may appear in the diff.

```sh
git diff --stat main...HEAD -- Tests/ agent/tests/ fixtures/   # exactly one line, the new file
```

If a move makes a test fail, **the move is wrong** — the test is not. Report it rather than
adjusting either side.

## Task 1 — Python: declare the sections, and check the order

Independent of tasks 2 and 3; may run first or alongside them.

`agent/clipwire-agent.py` currently has **no** section comments — verified, there are no
`# ===` or `# ---` banner lines in it. Add them, in the order the file already uses, plus a
table of contents in the module docstring listing the same names in the same order.

The nine sections, each with the declaration it starts at and that declaration's current line.
**Every line number below was read out of the file, and the order is the file's real order —
not a tidier one.**

| # | section | starts at | line |
|---|---|---|---|
| 1 | Frame codec | `MAX_PAYLOAD_BYTES` | 13 |
| 2 | Clip payloads | `TIMESTAMP_BYTES` | 64 |
| 3 | Freshness | `SEND_MINE` | 145 |
| 4 | Agent runtime | `AGENT_VERSION` | 342 |
| 5 | `class Agent` | `class Agent` | 439 |
| 6 | Clipboard state | `SUBPROCESS_TIMEOUT` | 1714 |
| 7 | Wayland clipboard | `wayland_socket_path` | 2126 |
| 8 | Selftest | `def _select_clipboard` | 2460 |
| 9 | Watchers and entry | `GPASTE_OBJECT_PATH` | 2510 |

Two places where the obvious guess is wrong, both verified:

- **Section 6 starts at `SUBPROCESS_TIMEOUT` (1714), not at `NeverReadyClipboard` (1690).**
  That class sits between `class Agent` and the timeouts and belongs with section 5.
- **`selftest` (2466) comes *before* the watchers (2723, 3054), not after them.** An earlier
  draft of this table listed "Entry" last because that is where an entry point usually goes.
  It is not where this one is. `main` (3207) and the `__main__` guard (3220) do end the file,
  so sections 8 and 9 are as the table says: selftest first, then the watcher machinery, then
  `main`.

**Declare the order the file has. Do not move code to match a nicer order** — moving code is
not this task's job, and a table that disagrees with the file would be "fixed" by exactly the
move this release forbids. Only banners and the docstring are added.

The check goes in a **new file**, `agent/tests/test_source_layout.py`. It must:

- read `clipwire-agent.py` **as text** and never import it — mirror how
  `TestModuleDefinitionOrder` in `test_watcher.py:3604` gets its source, which is already
  `AGENT.read_text()`;
- assert every declared section name appears exactly once as a banner comment;
- assert the banners appear in the order the table of contents declares;
- assert no top-level `def`/`class` sits above the first banner.

**Verify it by breaking it, not by watching it pass.** Move one banner, confirm red; restore,
confirm green. Report both observations.

Do **not** touch `test_watcher.py`, including its `TestModuleDefinitionOrder`. The two checks
overlap in spirit and that is fine; the existing one is frozen.

## Task 2 — Swift: the three self-contained extractions

Sequential with task 3 — both edit `main.swift`.

Create three files under `Sources/clipwire/`, each holding declarations moved **verbatim**
from `main.swift`, with the doc comments that sit above them:

- **`Hello.swift`**: `ProtocolConstants`, `private struct HelloPayload`, `decodeHello`,
  `SkewConstants`, `skewLogLine`.
- **`AgentStatus.swift`**: `final class AgentStatus`.
- **`Commands.swift`**: `runAgent`, `printStatus`, `initConfig`, `install`.

**`HelloPayload` is `private` and is the only such declaration in `main.swift`.** It must
travel with `decodeHello`, which is the sole user. This is the one hazard in the whole Swift
half: `private` is file-scoped, so leaving it behind either breaks the build or invites
widening the modifier — and widening is a real change wearing a move's clothes.

**No access modifier may be widened, anywhere.** Before and after, these two must match:

```sh
grep -rhcE '^(private|fileprivate)' Sources/clipwire/   # totals must be identical
```

Change no signature, no body, no comment text. Adding a file-header comment naming what the
file holds is the only addition allowed.

## Task 3 — Swift: the three larger extractions

Runs after task 2.

- **`ClipStateAnnouncement.swift`**: `sha256Hex`, `resolveCurrentClipState`,
  `ClipStateAnnouncement`, `persistClipState`, `announceClipState`.
- **`LocalChange.swift`**: `outgoingClipFrame`, `handleLocalChange`.
- **`HandleFrame.swift`**: `handleFrame`.

**`handleFrame` moves whole. Do not divide it**, however tempting its 431 lines are. Splitting
a function creates new signatures and a new control flow, which the tests cannot see because
they call it from outside — that is a behaviour change the criterion would not catch, which
is exactly why it is forbidden here rather than merely discouraged.

Afterwards `main.swift` should hold `AgentPaths`, `wireAgent` and the argument switch, and
nothing else — about 70 lines. Report its final line count.

## Verification for every task

```sh
rm -rf .build && swift build && swift test          # Swift must stay at exactly 243
python3 -m unittest discover -s agent/tests         # 311 existing + task 1's additions
git diff --stat main...HEAD -- Tests/ agent/tests/ fixtures/
```

Swift moving off 243 means something was renamed or dropped. Python staying at exactly 311
after task 1 means the new check was never wired in.

## What this plan deliberately does not do

`class Agent` (1251 lines) and `handleFrame` (431) are **not** decomposed. Both are candidates
for a later cycle with a review aimed at the decomposition itself, rather than one riding
under "the test diff is empty". Splitting the test files is likewise its own cycle, with the
mirror-image criterion — production frozen instead.
