# v3.1 implementation plan — the harness first, then the density fix

Design: [2026-08-01-v3.1-loop-and-density-design.md](../specs/2026-08-01-v3.1-loop-and-density-design.md)
(batya-approved). Read it first; this plan does not restate its reasoning.

## The gate

**Tasks 1–4 must all be finished, and the harness must have carried a text clip and an image
clip end to end, before task 5 begins.** If the harness runs late the density work waits; it
does not proceed alongside. Two novel things on one unclosed front is the shape that produced
three of this project's production defects.

## Task 1 — make the spawned command injectable

`Channel.attempt(host:)` hardcodes `/usr/bin/ssh` and `sshArguments(for:host:)`
(`Channel.swift:162-163`). `Channel` is a `final class` whose stored properties include
`private let config: Config` and `private let log: Log` (`:46-47`).

Add a way to supply the executable path and argv, **defaulting to exactly today's values**, so
that no production behaviour changes and no call site has to pass anything. The test target
injects; nothing reads the environment.

**No environment variable, for any reason.** The design says why: it would put "exec an
arbitrary command" into a tool that sits beside the owner's ssh keys in a public repository.
If injection seems to need one, stop and report rather than adding it.

Pin `sshArguments` with a unit test on its output strings — after this change it is the one
part of the connect path the harness does not cover, and it is a pure function, so a string
test is complete coverage rather than a token one.

## Task 2 — the fake clipboard pair

A `wl-copy` and a `wl-paste` that the agent cannot tell from the real ones, sharing state
through a file so that either side can change it.

- `wl-copy --type <mime>` reads stdin and stores it. **It must drain stdin fully**, which is
  what the real one does — measured, a 4 MiB write returns in 3 ms even against a locked
  session.
- `wl-paste --list-types` prints the stored types; `wl-paste --type <mime>` prints the body;
  `wl-paste -n` prints the text body.
- **A substitution mode**, because GPaste replaces the bytes it is given — measured, 105,700
  in and 180,287 out — and that substitution *is* the cause of the bug task 6 fixes. In this
  mode a read returns a different encoding of what was written, not what was written.

The substitution must be a real re-encode that drops `pHYs`, not a byte-mangle: task 6's fix
compares decoded pixels, so a fake that corrupts the image would make the comparison fail for
the wrong reason and prove nothing.

## Task 3 — the fake event source

A stand-in for `gdbus`, and all three of these or the harness silently tests nothing:

1. **It answers `introspect`, not only `monitor`.** `GPasteWatcher.available()`
   (`agent/clipwire-agent.py:3005`) runs `gdbus introspect` and returns `False` on `OSError` —
   what a Mac gives, having no `gdbus`. Serve only `monitor` and `available()` is false,
   `make_watcher` (`:3238`) picks the plain poller, and **every harness run passes while
   exercising polling only** — exactly the blindness the fake exists to remove, arriving as a
   green suite.
2. **It emits on any change of the shared state, not only on the agent's writes.** Otherwise
   the direct PC→Mac direction — a person copying on the PC — does not exist in the harness.
3. **It flushes every line.** Block buffering would delay lines past the pump and the safety
   net would declare a dead source, from buffering, with no defect anywhere.

The `Update` line is byte-exact to production: `('REPLACE', 'ALL', uint64 0)`. Check
`parse_gpaste_line` (`:2591`) and match what it parses, not what this plan remembers.

## Task 4 — the harness itself

A test that starts the Swift side with the spawn command pointed at
`python3 agent/clipwire-agent.py`, the fakes ahead of it on `PATH`, and a fake pasteboard on
the Swift side; then sends a clip each way, in both directions, text and image.

**It asserts its own world first and aborts if it is wrong.** The fakes on `PATH` are these
fakes; the agent is the one in this tree; and — from the agent's own log — **the event path is
live, not polling**. A harness that degrades to a weaker run and reports success is worse than
one that fails: this release's own pipe-write experiment did exactly that, and would have
reached a correct conclusion from invalid evidence.

**Then break it on purpose and watch it fail.** Change the freshness rule, or make one side
send the wrong frame type, and confirm the harness goes red. Report both observations. A
harness only ever seen passing is not evidence.

CI runs it on a **macOS runner** — the Swift half links AppKit. The existing Python matrix is
untouched.

## Task 5 — the store stops being the wire type

`ClipStateStore` (`ClipStateStore.swift:19`, a `struct`) currently loads and saves
`ClipState` — the same type `Freshness.decodePayload` (`Freshness.swift:140`) decodes off the
wire.

Give the store its own record type: the `ClipState` it already holds, plus an **optional**
local hash. Optional matters — absent means today's behaviour, so an existing store file on
the owner's Mac keeps loading with no migration step.

**The wire is not touched.** Adding the field to `ClipState` would have worked and been wrong:
both sides ignore unknown keys — verified, Python's `decode_clip_state` returns normally and
Swift's keyed container never asks for them — so a Mac-internal value would have travelled to
the PC *silently* rather than failing loudly.

Comment the new type with why it exists, naming this incident. Without that, the next tidying
pass collapses the two back together. An optional field that never appears on the wire is
hard to collapse by construction, which is the point of choosing it.

## Task 6 — keep the local bytes when the pixels already match

> **Superseded by measurement.** This task shipped and is inert: GPaste converts colour
> rather than preserving samples, so no content comparison fires. See the postscript in
> the design doc. The steps below are the record of what was built, not a plan to follow.

In `handleFrame`'s `.imageClip` case (`HandleFrame.swift:404`, writing at `:494` — these
drifted when task 6 edited this very file, so read them out of the source, not out of this
line): before
writing, if the local pasteboard already holds an image whose pixels are identical to the
incoming one, **keep the local bytes and adopt the peer's hash into the store's canonical
field**, recording the local bytes' own hash in the new local field.

**"Identical pixels" means byte equality of the two RGBA buffers after decoding both into the
same format** — one colour space, one channel order. GPaste drops the ICC profile as well as
`pHYs`, so comparing them "as decoded" produces differences that are real in the buffer and
meaningless in the picture, and chasing those is a day gone.

The startup seed compares against the **local** hash, which is what stops the false
`clipboard changed while apart` the naive version would produce.

## Task 7 — prove it in the loop, then on the machines

A harness test: the Mac sends a PNG carrying `pHYs`; the fake clipboard substitutes a
re-encode without it; a reconnect follows. Assert the Mac still holds the **original** bytes,
that the reconnect resolves `doNothing`, and that no `clipboard changed while apart` is
logged.

Then the same thing by hand on the real machines, measured the way the failure was measured:
`pixelsWide`/`pixelsHigh` against `NSImage.size`. **The PC must be unlocked** — a locked
session makes every read hang, which is settled and documented and not a fault to re-diagnose.

## Standing instructions for every task

- **Check every identifier and line number in your brief against the real file** before relying
  on it. v3's briefs contained 53 wrong symbols across fourteen tasks. Report which of mine
  were wrong; that report is part of the deliverable.
- **Build what the brief says.** If you disagree, do it as specified and report the
  disagreement separately rather than acting on it. Several of v3's worst near-misses were
  caught exactly this way.
- **Verify a check by breaking it**, not by watching it pass.
