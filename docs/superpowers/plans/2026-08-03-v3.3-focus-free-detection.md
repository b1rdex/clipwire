# v3.3 Focus-Free Detection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop the PC agent's change-detection loop from stealing keyboard focus, and stop it from
declaring a healthy GPaste dead when GPaste re-offers its own clipboard content.

**Architecture:** Two tiers. The **fast tier** asks GPaste for the uuid of its top history entry
over D-Bus (3–5 ms, no focus) every few seconds. The **slow tier** keeps today's
`wl-paste --list-types` probe, but rarely and gated, as the only thing that can see "GPaste stopped
tracking the clipboard". Each tier has its own verdict rule, because their inputs have opposite
properties. Reads of actual clipboard content stay on `wl-paste`, unchanged.

**Tech Stack:** Python 3.11+ (single-file agent, stdlib only, no new dependencies), `gdbus` CLI,
Swift 5 test harness, `unittest`, XCTest.

**Spec:** `docs/superpowers/specs/2026-08-03-v3.3-focus-free-detection-design.md` — batya-approved.
Read §4.0 and §4.0.1 before Task 4; they define the machine every later task implements.

## Global Constraints

- **The agent is one file with no dependencies beyond the stdlib.** `agent/clipwire-agent.py`.
  No pip, no apt, no new binary requirements. `gdbus` is already required and already probed by
  `GPasteWatcher.available()`.
- **Reads of clipboard content stay on `wl-paste`.** Spec §7. Nothing in this plan may fetch clip
  bodies from GPaste.
- **The probe payload never reaches a log line.** Spec §5.2. `GetElementAtIndex` returns
  `(uuid, text)`; only the uuid may be retained, and never logged either.
- **The standalone `PollingWatcher` path is untouched.** Spec §2. A machine with no GPaste keeps
  today's behaviour exactly. Everything here lives in the `GPasteWatcher` branch.
- **Both suites must stay green at every commit:** `swift test` (278 tests),
  `python3 -m unittest discover -s agent/tests` (356), `python3 Tests/fakes/test_fakes.py` (29).
- **Hash the bytes you read back, never the bytes you wrote.** Unchanged project rule; no task here
  touches content hashing, and any task that appears to needs to stop and ask.
- **Verify a check by breaking it.** Every task's final step deletes the implementation line and
  confirms the new test goes red. A test only ever seen passing is not evidence.

## Implementation note: the "monitor is on" gate

Spec §4.2 requires the slow tier to be gated on the monitor being on, so a tick cannot be a
guaranteed 3 s timeout into nothing. **The spec does not name the mechanism, and the obvious
candidate was measured and rejected during planning.**

`org.gnome.Mutter.DisplayConfig`'s `PowerSaveMode` property answers in 4–5 ms with no focus and
returned `0` with the monitor on. But **the monitor-off reading was never measured**, and the
spec's own mechanism for the hang (§1.4) is a *hotplug disconnect*, not DPMS — under which
`PowerSaveMode` may well stay `0` while the output list changes instead. Planning against an
unmeasured branch of an API is what this project keeps getting burned by.

**So the gate is implemented as the timeout itself, observed directly:** a slow-tier probe that
times out backs the slow tier off (Task 8). This is strictly better than the proxy — it needs no
new API, it has no unmeasured branch, and it covers *every* cause of a hanging `wl-paste`
including a locked session, which `PowerSaveMode` would miss entirely.

The `IdleMonitor` gate is unaffected: `GetIdletime` was measured working (Task 6).

`PowerSaveMode`'s monitor-off reading goes on the hardware-acceptance list (Task 11) so a future
cycle can adopt it as a cheap early exit if it turns out to be truthful.

```python
def history_uuid(state):
    """The uuid of the top history entry.

    Derived from `generation` -- which set_body() stamps on every WRITE -- and
    NOT from the whole state file, so a harness (or the substitution path) that
    rewrites `types` without making a new entry leaves this alone. That is the
    property the v3.3 fast tier rests on, so the fake must have it too: GPaste's
    re-offer of its own content changes the offered types and adds no history
    entry.

    A harness that wants to move the uuid without touching `generation` -- an
    entry deleted from the GPaste UI, say -- sets `history_uuid` explicitly.
    """
    explicit = state.get("history_uuid")
    if explicit:
        return str(explicit)
    digest = hashlib.sha256(("gpaste-history-%s" % state.get("generation", "0"))
                            .encode("utf-8")).hexdigest()
    return "%s-%s-%s-%s-%s" % (digest[0:8], digest[8:12], digest[12:16],
                               digest[16:20], digest[20:32])


def call_get_element_at_index(path):
    """`GetElementAtIndex(0)` -- (uuid, text) for the top of history.

    The text is deliberately included and deliberately NOT what the agent is
    allowed to use: the real method returns it, so a fake that omitted it would
    let a payload-logging regression pass unseen (spec 5.2).
    """
    state = fake.load(path)
    body = fake.body_bytes(state)
    text = body.decode("utf-8", "replace")[:40] if body else ""
    say("('%s', '%s')" % (history_uuid(state), text.replace("'", "")))
    fake.note(PROGRAM, "call GetElementAtIndex(0) -> uuid")
    return 0
```

```python
def start_gdbus_monitor(self):
    process = subprocess.Popen(
        [sys.executable, os.path.join(FAKES, "gdbus"), "monitor", "--session",
         "--dest", "org.gnome.GPaste", "--object-path", "/org/gnome/GPaste"],
        stdout=subprocess.PIPE, stderr=subprocess.DEVNULL, text=True,
        env=dict(os.environ, CLIPWIRE_FAKE_CLIPBOARD_STATE=self.state))
    self.addCleanup(process.terminate)
    os.set_blocking(process.stdout.fileno(), False)
    time.sleep(0.2)                       # let it take its baseline digest
    process.stdout.read()                 # discard the "Monitoring signals" banner
    return process

def drain(self, process, seconds):
    """Every Update line the monitor emitted within `seconds`."""
    time.sleep(seconds)
    text = process.stdout.read() or ""
    return [line for line in text.splitlines() if "Update" in line]
```

```python
def _env_seconds(name, default):
    """An interval overridden from the environment, or `default`.

    Exists for PairingHarness, which needs sub-second tiers to exercise in
    seconds what production does in minutes. Production sets none of these, so
    the constants below are what a real agent runs.

    Anything unparseable or non-positive returns the default rather than
    raising: a typo in a harness must not produce a zero-second poll that spins
    a core, and must not take down an agent on a machine where the variable was
    never meant to be read.
    """
    raw = os.environ.get(name)
    if not raw:
        return default
    try:
        value = float(raw)
    except ValueError:
        return default
    return value if value > 0 else default
```

```python
            if raises is not None:

        self.assertEqual(
            self.probe(b"('ecf318fd-a295-40a8-b591-9721fcf7cbcc', 'CD-3167')\n"),
            "ecf318fd-a295-40a8-b591-9721fcf7cbcc")

        self.assertIsNone(self.probe(b"", returncode=1))

    def test_a_timeout_is_not_measured(self):
```

```python
    THE TOKEN THE FAST TIER COMPARES, and the reason v3.3 exists. GPaste
    re-offers an image one to six seconds after any copy -- measured, the

    looked like one whose event source had died. A history entry is not created

    compared for equality with a previous reading, because "the call failed" and
    "the clipboard did not change" are opposite conclusions. Treating them alike
    turns a renamed method into a permanent false 'tracking dead' verdict --
    exactly the state whose latch this release does not yet clear.

    The reply also carries the top item's TEXT, which may be a password. Only
    the uuid is returned and neither is ever logged (spec 5.2).
    """
    try:
        result = run(
            ["gdbus", "call", "--session", "--dest", GPASTE_BUS_NAME,
             "--object-path", GPASTE_OBJECT_PATH,
             "--method", "%s.GetElementAtIndex" % GPASTE_INTERFACE, "0"],
            capture_output=True, timeout=GPASTE_CALL_TIMEOUT, env=clipboard_env(),
        )
    except (subprocess.TimeoutExpired, OSError):
        return None
    if result.returncode != 0:
        return None
    # ('<uuid>', '<text>') -- the first single-quoted field. Deliberately not a
    # full GVariant parse: anything this does not recognise is None, which the
    # callers already treat as "no evidence", rather than a guess.
    text = result.stdout.decode("utf-8", "replace")
    parts = text.split("'")
    if len(parts) < 2 or not parts[1]:
        return None
    return parts[1]
```
